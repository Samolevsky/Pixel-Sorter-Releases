# Pixel Sorter

[Pixel Sorter](https://pixelsorter.samolevsky.com/) creates glitch art by sorting image pixels with adjustable masks, angles, and color effects.

## Downloads

Open the [latest release](https://github.com/Samolevsky/Pixel-Sorter-Releases/releases/latest) and choose the file for your computer:

| Platform | Installer |
| --- | --- |
| macOS Apple Silicon | `Pixel.Sorter-<version>-mac-arm64.dmg` |
| macOS Intel | `Pixel.Sorter-<version>-mac-intel.dmg` |
| Windows 64-bit | `Pixel.Sorter-<version>-win-x64.exe` |

macOS installers are signed and notarized. Windows installers are unsigned. GitHub converts spaces in uploaded filenames to dots.

## Updates

Installed copies check for updates automatically. You can also choose **Check for Updates…** from the application menu on macOS or **Help** on Windows. Accept the download, export any projects you want to keep, then restart to install. **Help → Release Notes** opens the release history.

If an older copy has no **Check for Updates…** command, install the latest download once to enable in-app updates.

This repository contains the download README and release files. Pixel Sorter's source code is private.
